# 🚀 2단계 - 칸반 보드 관리(수정)

## 기능 구현 목록

1. Review 상태 추가
- [x] 상태에 review를 추가한다
- [x] kanbanboard에 review 상태 박스를 추가한다.
- [x] 다이얼로그 상태 선택 목록에 review 를 추가한다.

2. 상태별 태스크 특징 적용
- [x] 상태별 삭제 가능 여부 규칙을 정의한다. (To Do, In Progress만 삭제 가능)
- [x] 상태별 담당자 필수 여부 규칙 정의한다. (To Do만 담당자 미지정 가능)
- [x] 상태 전이 허용 규칙을 정의한다.
    - To Do → In Progress 
    - In Progress → To Do, Review
    - Review → In Progress, Done
    - Done → To Do
- [x] 허용되지 않은 상태 전이는 차단한다.

3. 태스크 수정 다이얼로그 생성  
- [x] DialogMode에 수정, 생성 모드를 추가한다.
- [x] DialogMode (CREATE, EDIT)에 따라 제목과 버튼 텍스트를 동적으로 변경한다
- [x] 담당자 선택지에 `없음` 옵션을 추가한다 (To Do 상태에서만 미지정 가능)

4. 태스크 카드 클릭 시  다이얼로그 노출
- [x] TaskCard의 onClick 이벤트에 다이얼로그 열기 로직을 연결한다
- [ ] 수정 모드에서 기존 태스크 정보를 초기값으로 로드한다

5. 태스크 수정 기능 구현
- [ ] 입력된 제목이 비어있는지 확인하고, 비어있으면 스낵바로 알림한다
- [ ] 입력된 태그가 유효한지 확인하고, 유효하지 않으면 스낵바로 알림한다 
- [ ] 대상 상태가 In Progress, Review, Done이고 담당자가 `없음`이면 스낵바로 알림한다 
- [ ] 현재 상태에서 대상 상태로의 전이 규칙을 확인하고, 허용되지 않으면 스낵바로 알림한다 
- [ ] 수정 성공 시 스낵바 메시지를 노출한다 

6. 태스크 삭제 기능 구현
- [ ] 태스크의 현재 상태가 Review 또는 Done인지 확인하고, 해당 상태면 스낵바로 알림한다 
- [ ] 태스크의 현재 상태가 To Do 또는 In Progress인 경우 KanbanBoardState에서 태스크를 제거한다
- [ ] 삭제 성공 시 스낵바 메시지를 노출한다
